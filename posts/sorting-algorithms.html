三种经典排序算法（冒泡 / 插入 / 快速）

2026-09-08 阅读约 — 分钟 JavaScript算法

排序算法是算法学习的入门第一课。这篇文章用原生 JavaScript 实现了三种经典排序算法：冒泡排序、插入排序、快速排序，手写源码 + 复杂度分析，文末还提供了一个在线演示：生成随机数组，同时运行三种算法并对比耗时。

冒泡排序 Bubble Sort

基本思想：相邻元素两两比较，逆序就交换。每一轮结束后，当前区间最大值会"冒泡"到最右边，下一轮就不用再碰它了。

function bubbleSort(arr) {
  const n = arr.length;
  for (let i = 0; i < n - 1; i++) {
    for (let j = 0; j < n - 1 - i; j++) {
      if (arr[j] > arr[j + 1]) {
        [arr[j], arr[j + 1]] = [arr[j + 1], arr[j]];
      }
    }
  }
  return arr;
}
  • 优点：实现最简单，代码最容易读懂
  • 缺点：交换次数多，性能最差，只适合教学演示
  • 特点：稳定排序（相等元素相对顺序不变）

插入排序 Insertion Sort

基本思想：从第二个元素开始，把当前元素插入到左侧"已排序区间"的正确位置，就像打扑克牌时整理手中的牌。

function insertionSort(arr) {
  const n = arr.length;
  for (let i = 1; i < n; i++) {
    const current = arr[i];
    let j = i - 1;
    while (j >= 0 && arr[j] > current) {
      arr[j + 1] = arr[j];
      j--;
    }
    arr[j + 1] = current;
  }
  return arr;
}
  • 优点：对基本有序的数据特别快（最好 O(n)），实现简单、稳定
  • 缺点：逆序数据依然是 O(n²)
  • 应用：引擎里常把它用作小区间排序的兜底（比如 Timsort）

快速排序 Quick Sort

基本思想：选取一个枢轴（pivot），把数组分成"小于枢轴"和"大于枢轴"两半，再递归处理。这里用的是 Lomuto 分区 + 区间末尾元素作枢轴。

function quickSort(arr, left = 0, right = arr.length - 1) {
  if (left >= right) return arr;

  const pivot = arr[right];
  let i = left;
  for (let j = left; j < right; j++) {
    if (arr[j] < pivot) {
      [arr[i], arr[j]] = [arr[j], arr[i]];
      i++;
    }
  }
  [arr[i], arr[right]] = [arr[right], arr[i]];

  quickSort(arr, left, i - 1);
  quickSort(arr, i + 1, right);
  return arr;
}
  • 优点：平均性能最好的通用排序之一，O(n log n)
  • 缺点：最坏 O(n²)，递归深度最坏 O(n)（对已排序数组），不稳定的

小结

三种算法各有战场：数据量小、基本有序用插入排序最快；通用场景首选快速排序；冒泡排序则基本只存在于教科书和面试题里。上面的演示可以直接运行对比三者耗时，多试几组不同规模的数据吧。
