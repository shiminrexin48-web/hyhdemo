CSS Flexbox 布局完全指南

2026-08-20 阅读约 — 分钟 CSS布局

Flexbox（弹性盒子）是 CSS3 引入的布局模型，专为一维布局而生：它让「一行里放几个元素、怎么对齐、怎么分配空间」这件事变得极其简单。

第一步：理解两根轴线

Flex 布局的核心是轴线（axis）。容器有一个 主轴（main axis，由 flex-direction 决定，默认水平）和一个 交叉轴（cross axis，与主轴垂直）。所有属性都在围绕这两根轴工作：

  • justify-content —— 控制 主轴 上的排列与剩余空间分配
  • align-items —— 控制 交叉轴 上的对齐
  • gap —— 控制子元素之间的间距（比 margin 干净得多）

常用属性速查

属性 说明 常用值
flex-direction主轴方向row（默认）/ column
justify-content主轴对齐center / space-between / space-around
align-items交叉轴对齐center / stretch（默认）/ flex-start
flex-wrap是否换行nowrap（默认）/ wrap
flex-grow按比例瓜分剩余空间1（均分）
flex-shrink空间不足时收缩比例1（默认）
flex-basis分配前的初始尺寸200px 等

5 个经典实战场景

① 水平 + 垂直居中（告别 margin 大法）

.box {
  display: flex;
  justify-content: center;   /* 主轴居中 */
  align-items: center;       /* 交叉轴居中 */
}

② 顶部导航（左 Logo 右菜单）

你正在看的这个博客导航就是这么写的：Logo 在左，菜单靠右，中间留白全自动：

.nav {
  display: flex;
  align-items: center;
  gap: 1.5rem;
}

.nav-links {
  margin-left: auto;   /* 把菜单推到最右边 */
  display: flex;
  gap: .5rem;
}

③ 卡片网格一行放多少张

.post-list {
  display: flex;
  flex-wrap: wrap;
  gap: 1.25rem;
}

.post-card {
  flex: 1 1 320px;   /* 至少 320px 宽，空间多了自动均分 */
  min-width: 0;
}

优点：不用媒体查询，窗口变窄时自动换行；正好填满一行时卡片会自动拉伸填满。

④ 双栏布局

.layout {
  display: flex;
  gap: 1.5rem;
}
.main {
  flex: 3;           /* 主内容占 3 份 */
}
.sidebar {
  flex: 1;           /* 侧边栏占 1 份 */
}

⑤ 粘性页脚（页面太矮时页脚也在底部）

body {
  display: flex;
  flex-direction: column;
  min-height: 100vh;
}
main {
  flex: 1;           /* main 吃掉所有剩余高度 */
}

你现在这个博客的页面就用了这招——内容再少，页脚也会沉在视口底部。

注意事项

flex 的 flex: 1 1 320px 是 grow / shrink / basis 的简写，语义是「初始 320px，多了就长，少了就缩」——配合 flex-wrap: wrap，是构建响应式卡片网格的黄金组合。

小结

先记住一句话：主轴方向由 flex-direction 决定，其他属性围绕它展开。把上面 5 个场景反复写几遍，Flexbox 就是你的肌肉记忆了。
